# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

数据备份与恢复：侧栏「数据备份」可将全部事项导出为本地 JSON 文件，也可选择备份文件导入恢复；导入内容无效时保留原有数据并给出提示，刷新后数据保持一致。

批量操作：勾选多个事项后可一次切换为待处理/处理中/已完成或一次移除；未勾选时提示先选择，移除前需再次确认，刷新后勾选状态自动清空。

```bash
npm run build   # 构建
npm test        # Playwright 浏览器回归（备份恢复/批量操作/刷新持久化/原有功能）
```
